# 灵兔拆包智录：品牌升级与数据保留

2.6.1 使用新产品名称与带灵兔徽章的原软件图标。软件界面布局、配色与功能流程保持原样，关于页和手机设置页补充官网、教程、更新记录和源码链接。

## 下载与升级

1. 在 https://record.lttlt.top 查看版本、预发布说明、文件大小和 SHA-256。
2. Windows 完成当前录像并退出，再运行安装器覆盖升级。安装目录身份不变，不需先卸载。
3. Android 安装同签名 APK 覆盖升级；不要为改名卸载旧 APP。证书不匹配时停止安装，不生成替代密钥。
4. 升级后核对录像目录、Excel、历史记录与已配对手机。保留更新前备份。

现有 `%LOCALAPPDATA%\UnpackVision`、SQLite、设置键、录像与便携索引、Excel 结构和 Android 应用身份均继续使用。内部程序文件名与兼容下载资产名属于升级契约，可能保留旧名。

## 卸载与重装

安全卸载默认保留业务数据，重装后选择原录像目录及 Excel。永久删除数据是独立操作，继续保留原有两次确认机制。品牌升级不需要执行删除。

## 官网维护

先完成软件构建、签名校验、哈希与 GitHub 预发布资产上传，再把同一版本的 `desktop-update.json`、`mobile-update.json` 和下载元信息复制到官网并部署。不要使用 `/releases/latest` 作为预发布下载入口。

网站为已有公开 Sites 项目，`website/.openai/hosting.json` 中的项目身份保持不变。`record.lttlt.top` 的 HTTPS 生效后，才启用 `cbzl.lttlt.top` 到新站的 301 跳转；路径和查询参数继续保留。仓库改名后保留旧仓库名供 GitHub 重定向使用，不创建同名新仓库。
