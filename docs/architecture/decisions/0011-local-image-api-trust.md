# ADR 0011：本机图像 API 的权限边界

本机兼容服务的图像处理和条码识别 API 接收显式输入/输出文件路径，这是当前 Windows 用户授权的完整本地文件能力，不是可共享的受限网络 API。路径可位于用户选择的任意本地工作目录；不通过伪造固定根目录来改变既有能力。

约束：主机监听仅允许字面回环 IP 或 localhost，固定优先使用已校验的 hosting URLs，不能由 Kestrel endpoint 配置扩展网络监听；请求还必须来自回环连接且 Host 为回环 IP/localhost，防止错误网络配置和 DNS 重绑定。图像端点继续校验随机 API 密钥，密钥使用当前用户 DPAPI 保存。服务不得提权运行，也不支持反向代理或网络共享此密钥。手机网络功能仍由独立 StationHost 的 HTTPS/配对权限模型承担。

CodeQL 的请求路径流本身真实存在；在上述边界下，持有密钥的同权限本机调用者被明确授权读写图片，因此不是目录穿越带来的跨权限访问。告警应携带边界测试、认证 smoke 与该 ADR 进行人工分类，不能通过字符串清洗、GetFullPath 或忽略扫描器冒充修复。

如未来需要受限或远程图像处理，必须改用服务批准的文件 ID/目录，处理 UNC、重解析点、覆盖和角色权限后再开放网络；不复用本机完整文件能力。
