# 灵兔拆包智录 2.6.1 预发布说明

本版本将拆包智录归入「灵兔 LTTLT」品牌，保留原软件界面风格与业务流程。

- 产品显示名称更新为「灵兔拆包智录」。保留原纸箱和摄像头图标主体，在右下角加入灵兔品牌徽章。
- Windows 关于页和 Android 设置页增加产品官网、使用教程、更新记录和源码入口。
- 官网统一为 https://record.lttlt.top，旧官网保留跳转；源码仓库更名为 https://github.com/907609732/lingtu-recorder。
- 修复预发布更新入口：官网与更新清单使用明确发布版本，不再误指向 GitHub 旧稳定版。
- 保留 Velopack 包身份、Android 包名与原签名、数据库、设置、录像命名、Excel 格式及配对协议。
- 保留远端 2.5.3 的 CI 进程测试兼容修复，并保护固定哈希的第三方许可证原始字节。

Windows 安装器未取得可信 Authenticode 代码签名，因此本版本不能标记为正式稳定版。首次安装可能出现 SmartScreen 提示，请核对来源与 SHA-256。

8/16 路录像、多盘故障切换、长时间手机推流的工程基础继续保留。未经当前实机验收的能力不得视为稳定生产能力。构建、模拟测试和设备验收分别记录，未执行项不宣称通过。

旧客户端若仍只检查 GitHub 稳定版本，请从官网手动下载安装器覆盖升级，或安装同签名 APK；无需删除旧数据或重新建立录像目录。详见 [品牌升级与数据保留](../operations/brand-upgrade.md)。

原计划 v2.6.0 标签因 Windows Runner 冷启动测试限额及官方媒体下载中断而未发布完整安装包，标签保持原位。本次递增补丁版本，延长仅用于环境隔离测试的启动预算，并给固定哈希的媒体下载增加有限重试；业务行为保持不变。
